# Autosave Plugins

Public home for CAD autosave plugins.

This repository is licensed under MIT. See `LICENSE`.

Currently included:

- `plugins/inventor-autosave`: Inventor Autosave for Autodesk Inventor 2026

Release automation lives in GitHub Actions and publishes installer artifacts for tagged releases.

Third-party dependency notices live in `THIRD-PARTY-NOTICES.md` and are bundled into the downloadable release assets.
